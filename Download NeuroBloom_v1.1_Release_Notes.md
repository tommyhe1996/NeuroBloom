# 🌸 NeuroBloom v1.1 – Build & Refine Release

📅 **Release Date**: July 11, 2025  
🏷 **Version**: `v1.1`  
🔖 Tagline: *"Build & Refine — expanding clarity, accessibility, and creative self-expression."*

---

## ✨ What’s New

NeuroBloom v1.1 marks a major milestone in evolving the platform into a more inclusive, neurodivergent-friendly space for mood journaling and poetic reflection. This release focuses on UI refinement, accessibility upgrades, documentation expansion, and developer onboarding.

---

## ✅ Key Features & Improvements

### 🌈 User Experience & Accessibility
- Improved color themes and layout structure for better readability
- Softer UI tones and spacing adjustments to reduce cognitive load
- More inclusive, calming affirmation language for mood pairings

### 📤 Export & Visualization
- New export functions for journal entries (TXT, PDF)
- Framework for future emotion graph visualization (under planning)

### 🧠 Mood-Affirmation Pairs
- Review and refinement of tone for inclusivity, clarity, and emotional support
- Neurodivergent-friendly affirmations now prioritized in matching logic

### 🐛 Bug Fixes
- Resolved UI glitches in mood picker and export features
- Improved responsiveness for mobile and low-vision environments
