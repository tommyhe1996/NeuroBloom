# 🛣️ NeuroBloom Roadmap

Welcome to the official roadmap for **NeuroBloom** — a neurodivergent-friendly journaling app designed for emotional expression, poetic reflection, and peace of mind.

This roadmap outlines planned features, milestones, and goals for upcoming versions.

---

## ✅ Version 1.0 (Released)
- [x] Emoji-based mood selection
- [x] Daily poetic reflection entries
- [x] Custom affirmation generator
- [x] Simple export feature (TXT format)
- [x] Neurodivergent-friendly UI prototype
- [x] Core README, CONTRIBUTING.md, CODE_OF_CONDUCT.md

---

## 🔄 In Progress — Version 1.1
Target: **August 2025**

### ✨ Feature Additions
- [ ] Font size toggle for accessibility
- [ ] Soundtrack integration for reflection ambiance
- [ ] Expanded export formats (PDF, Markdown)
- [ ] Mood search + filter
- [ ] Community affirmation sharing module

### 💡 Enhancements
- [ ] Mobile emoji layout fix
- [ ] Improved UI contrast
- [ ] Tooltips for new users

---

## 🌱 Future Plans (v1.2+ and beyond)
- 🔒 Encrypted mood storage
- 📅 Weekly/monthly mood reports with visualization
- 🎨 UI themes (calm mode, high-contrast mode)
- 🌍 Multi-language support
- 🤝 GitHub Discussions community integration expansion
- 🧘 Guided reflection flows
