# 🌱 Contributing to NeuroBloom

Thank you for your interest in contributing to NeuroBloom!  
This project is a creative, neurodivergent-friendly journaling app designed for emotional expression, poetic reflection, and peace of mind.

We welcome **developers, designers, artists, writers, and dreamers** who want to grow with us.

---

## 🧭 What You Can Contribute

Here are some ways to get involved:

- ✨ Add features (e.g. export tool, visualization, affirmation library)
- 🎨 Improve the UI (soft, accessible design)
- 💬 Help refine the mood/affirmation language
- 🐞 Report or fix bugs
- 📖 Add documentation or tutorials
- 🎶 Suggest ambient sound options

---

## 🛠️ How to Contribute

1. **Fork this repository**

2. **Clone your fork**  
   ```bash
   git clone https://github.com/your-username/NeuroBloom.git
   cd NeuroBloom
   ```

3. **Create a new branch for your feature**  
   ```bash
   git checkout -b feature/your-feature-name
   ```

4. **Make your changes**  
   Use the folders:
   - `/ui` for HTML/CSS
   - `/scripts` for Python or JS logic
   - `/moodlogs` for structure templates

5. **Commit with clear message**  
   ```bash
   git commit -m "Add: new mood chart visualization"
   ```

6. **Push to your fork**  
   ```bash
   git push origin feature/your-feature-name
   ```

7. **Open a Pull Request**

---

## 🧠 Neurodivergent-Friendly Guidelines

We aim for contributions to be:

- 🌿 **Sensory-friendly**: pastel palettes, low visual noise
- 🧘‍♂️ **Non-overwhelming**: minimal pressure or urgency
- ✨ **Creative**: affirmations, metaphors, and emotional reflection
- ♿ **Accessible**: support screen readers and keyboard navigation

---

## 💬 Communication Style

- Be kind and patient — assume good intentions  
- Use gentle language  
- It's okay to take breaks or go at your own pace
