- [x] Create a **new Project** named: `v1.1 Planning`
- [x] Use **board layout** (columns: `To Do`, `In Progress`, `Done`)

## 🗂️ Organize Issues into Columns

Check that each issue has appropriate labels:
- [x] `enhancement` — for new features
- [x] `bug` — for UI/logic issues
- [x] `community` — for user-contributed or community-related ideas
- [x] `accessibility` — for inclusive design features
