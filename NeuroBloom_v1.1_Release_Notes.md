
# 🌸 NeuroBloom v1.1 – Release Notes

**Release Date:** July 2025  
**Status:** ✅ Completed & Active  
**License:** MIT

---

## ✨ Overview

This release marks the completion of version **v1.1** of the NeuroBloom project — a neurodivergent-friendly mood journaling and reflection platform designed to support creativity, emotional regulation, and poetic self-expression. The v1.1 sprint focused on accessibility, user experience, bug fixes, and project organization to ensure a smoother and more inclusive experience for all users.

---

## 🔧 Key Updates & Improvements

### 🛠️ Feature Enhancements
- **Export & Visualization Tools**: Added functions to export journal entries to TXT and PDF, and introduced visual graph features for emotion tracking.
- **Mood-Affirmation Pair Refinement**: Improved the tone, clarity, and inclusivity of mood-affirmation text combinations.
- **Font Size Adjustment Button**: Introduced an adjustable font size feature for low-vision or neurodivergent users.

### 🎨 UI & Accessibility
- **UI Expansion**: Enhanced layout spacing, color theming, and font styles to improve readability.
- **Sensory-Friendly Design**: Optimized design for neurodivergent users by reducing visual clutter and overstimulation.

### 🐞 Bug Fixes
- **Mobile UI Fixes**: Resolved issues with the mood emoji picker on mobile screens.
- **Export Errors**: Fixed export tool crashes and input issues during export.
- **Color Conflict Resolution**: Addressed inconsistencies in the color theme files.

### 📚 Documentation
- **New `PROJECTS.md`**: Added a live link to the sprint board and outlined active development phases using a Kanban structure.
- **Updated `README.md`**: Improved badge display, folder structure view, and added links to the contributing and documentation pages.
- **New `Download_docs_README.md`**: Provides a centralized view of creative and layout PDFs with detailed usage instructions.
