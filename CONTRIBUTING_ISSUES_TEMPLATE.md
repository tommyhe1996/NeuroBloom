# 🧩 Contributing Tasks → GitHub Issues Template

Below are the tasks from `CONTRIBUTING.md` ready to be created as GitHub Issues for better tracking and collaboration.

---

## 🔧 Add Export & Visualization Tools
**Description:**  
Implement export functions for journal entries to TXT and PDF. Consider adding visualization features (e.g., emotion graphs) and an affirmation suggestion library.

---

## 🎨 Refine and Expand UI for Accessibility
**Description:**  
Enhance UI design with better layout, spacing, and soft color themes to support neurodivergent users. Focus on readability and sensory-friendly design.

---

## 💬 Review and Enhance Mood-Affirmation Pairs
**Description:**  
Edit and review the affirmation text to ensure it's inclusive, calming, and fits neurodivergent-friendly tone and intention.

---

## 🐞 Track and Resolve Bugs in Mood Picker or Export Features
**Description:**  
Identify bugs in any part of the app. Report error logs, crashes, and UI glitches in journal input, export, or mood selector.

---

## 📚 Create User Guide and Developer Setup Docs
**Description:**  
Write a basic tutorial for users on how to journal with NeuroBloom and a separate setup guide for developers to contribute locally.

---

## 🎶 Add Ambient Sound Features for Journaling Sessions
**Description:**  
Suggest or implement ambient background music or sounds that can be toggled during journaling for enhanced focus.
